## 二、搬瓦工套餐体系：从入门KVM到CN2 GIA，差别在哪

可选机房主要在美国（DC2 QNET、DC4 MCOM、DC8 ZNET、FMT、USNJ、USNY等）、加拿大（CABC_1）、荷兰（EUNL_3）等地，共9个机房。

### 3. 香港/东京/新加坡/大阪CN2 GIA套餐：延迟最低，价格最高

## 七、几个常见问题

**搬瓦工和BandwagonHost是什么关系？**
是同一家。BandwagonHost是英文品牌名，因为拼音"banwagong"和英文发音接近，中文用户就叫它搬瓦工。官网主域名bandwagonhost.com在国内可能无法直接访问，镜像域名bwh81.net可以正常打开，两个域名指向同一套系统，账号和套餐通用。

**CN2 GIA和CN2 GT有什么区别？**
CN2 GIA（AS4809）是中国电信最贵的传输线路，稳定性最好，丢包率最低。CN2 GT（AS4809）原本也是优质线路，但自2019年以来拥堵严重，体验已经接近普通163线路。搬瓦工的CN2 GIA-E套餐走的是CN2 GIA，常规KVM套餐走普通线路，没有CN2 GT选项。

**香港/东京CN2 GIA值不值那个价？**
取决于你的使用场景。如果只是个人科学上网或远程办公，洛杉矶CN2 GIA-E延迟在150ms左右，完全够用，价格只有香港的1/5。如果你跑的是面向国内用户的电商网站、实时性强的应用，亚洲机房的低延迟（20ms以内）确实能带来明显体验差异，这时候多花钱是值得的。

**限量版套餐会一直有货吗？**
不会。限量版套餐库存有限，卖完就下架，补货时间不固定。THE PLAN系列历史上补货过几次，但每次都是秒空。如果看到合适的限量版套餐有货，建议尽快下单，犹豫几天可能就没了。

**搬瓦工适合新手吗？**
搬瓦工是self-managed服务，意味着不提供代管技术支持，需要自己会基本的Linux操作。但KiwiVM面板把开关机、重装系统、迁移机房这些常用操作做成了图形化按钮，零基础也能完成基本管理。如果连命令行都不想碰，可能需要考虑带cPanel或Plesk的托管型主机，但价格会贵很多。
